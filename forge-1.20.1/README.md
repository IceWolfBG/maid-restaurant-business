# 女仆餐厅：营业中 · Maid Restaurant: Now Open

> 车万女仆（Touhou Little Maid）× 女仆餐厅（Maid Restaurant）× 下单了（Order to Cook）三方联动附属，让女仆真正把一家餐厅「开起来」：自动接单、烹饪、备菜、打包、配送、洗盘一条龙，并提供外卖配送站与完善的防卡死保护。

A Touhou Little Maid × Maid Restaurant × Order to Cook integration addon that runs a fully automated maid restaurant: auto ordering, cooking, prep, packaging, delivery, dishwashing, plus a takeout delivery station and robust anti-stuck protection.

## 功能特性

### 自动化经营（随打单机等级逐步解锁）
- **自动接单**：依据周围食材与订单价值自动选择订单，可配置延迟与优先级。
- **自动烹饪**：厨师女仆按订单烹饪，支持「能做多少做多少」的部分匹配，正确处理多原料 / 多替代原料配方（如鸡蛋与海龟蛋互相替代）。
- **智能备菜调度**：背包里已有成品的女仆优先把成品送回操作台（备菜），其余空闲厨师不停火继续做新菜；备菜不再阻塞烹饪发布，多厨师并行且不重复发布同一道菜。
- **自动打包 / 装盘**：侍者女仆在操作台自动打包外卖袋、装盘堂食。
- **自动配送**：侍者女仆把餐盘精准送到对应顾客，严格按订单 ID 匹配顾客，避免送错人；找不到顾客时安全销毁餐盘并提示，杜绝卡死。
- **自动洗盘 / 收盘**：收集脏盘并用洗碗机清洗，干净盘子放回盘子架；收盘子不会误收顾客正在吃的盘子。

### 酒狐速递站（外卖）
- 一个可容纳 5 个外卖袋的配送站方块，女仆把打包好的外卖袋放入即可。
- 配送耗时按订单坐标与速递站的水平距离、配送速度计算，受打单机等级加成；含最小 / 最大时间钳制与手续费（随等级递减、设下限）。
- 配送进度、每格状态、等级费率均可在 GUI 查看；玩家不能手动存入 / 取出，配送结束自动结算给放入外卖袋的女仆主人。
- 速递站被破坏、塞满、超时等异常都会安全处理并掉落 / 清理，不会让女仆卡住。

### 厨具管理（按打单机隔离）
- 以**每台激活的打单机**为单位统计周围煎锅 / 汤锅 / 蒸笼 / 厨锅（兼容森罗物语：厨房与农夫乐事）的数量与占用。
- 发布烹饪任务时校验「该打单机」是否还有对应类型的空闲厨具，避免多个女仆抢同一个锅；A、B 两台打单机各自独立计数、互不阻塞。
- 缺少厨具 / 没有空闲厨具时，女仆会以可爱语气气泡提示，可重复触发。

### 稳定性与防卡死
- 所有自动化环节（打包 / 配送 / 烹饪 / 备菜 / 洗盘 / 收盘）都有独立的超时保护、失败重试与任务自愈，超时时间全部可在配置中调整。
- 中心化 `TaskManager`：以激活打单机为中心、在配置范围内统一缓存女仆 / 容器 / 操作台 / 厨具，避免每个女仆各自全局遍历，显著降低多女仆时的性能开销；**不做全局 / (0,0,0) 检索**。
- 多人服务器兼容：任务、厨具、配送识别均在服务端权威处理。

### 反馈与沉浸
- 复用并扩展车万女仆的聊天气泡：烹饪开始 / 完成、取食材、备菜完成、配送、打包、洗盘、缺食材（最多列 3 种）、缺厨具、速递站已满等，文案为可爱女仆语气，带全局冷却避免刷屏。
- 关键动作（备菜放入、洗盘放回盘子架等）附带副手手臂摇摆动画。

## 快速开始

1. 放下打单机与操作台（打包台），并在打单机附近的物品展示框里放入餐厅菜单以激活自动化。
2. 安排若干**厨师**职业与**侍者**职业的车万女仆在打单机周围工作。
3. 放上厨具（煎锅 / 汤锅 / 蒸笼 / 厨锅）、食材容器、洗碗机、盘子架。
4. 做外卖则额外放下「酒狐速递站」，侍者会把外卖袋送进速递站自动配送结算。
5. 随着打单机升级，更多自动化能力逐步解锁；也可在配置里关闭等级限制直接全开。

## 配置文件

| 文件 | 内容 |
|---|---|
| `maid_restaurant_business-common.toml` | 总开关（自动接单 / 接外卖 / 打包 / 配送 / 洗盘）、等级解锁、扫描范围、待处理订单上限、气泡冷却、好感度加成等 |
| `maid_restaurant_business-takeout.toml` | 酒狐速递站：基础 / 每级配送速度、最小最大配送时间、基础 / 每级手续费、手续费下限 |
| `maid_restaurant_business-safety.toml` | 各环节任务超时、已分配 / 待处理任务超时、厨具占用超时、最大重试、检测间隔、卡住判定倍率 |

配置在服务端权威保存（common），单人 / 多人均持久化，重进游戏不丢失。
